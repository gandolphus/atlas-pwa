Idea: clicking a tile takes the whole screen; the atlas fades to a faint ghost and a tiny minimap (top-right) marks where the word sits, turning green when done.
Layout: large centred sentence, quiet left/right margins (English, other sentences / hook, forms) fade in only as steps unfold, so 3440x1440 never feels empty.
Optimises: flow state. Guess -> meet -> recall-until-right -> done, Enter on the done page jumps straight to the next new word without touching the atlas; Esc returns.
Learned card: same page, English cue + cloze first, then reveal fills the margins (other sentences, forms, grammar, hook); Enter goes to next review.
Trade-offs: atlas context is nearly gone while learning (minimap only), tiles never move; at 1440 the margins are narrow; zero chrome means little signposting beyond the Esc chip.
