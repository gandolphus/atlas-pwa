# E - centered stage
Idea: one fixed-size card floats dead-centre over the atlas; the atlas stays put behind it (dimmed + 3px blur, no reflow). Esc or click outside closes.
Learn flow: guess -> meet -> recall-until-right -> done, 4 progress dots, Enter-first, English never before the guess. Done: tile behind lights green; Enter crossfades to the next new word, Esc dissolves the card.
Learned card: same stage, ask-first, reveal, 1/Enter auto-rate, Down = deepen row (space is reserved, so nothing jumps).
Optimises: zero layout motion, one focal point (big word + one input), identical geometry at every step.
Trade-offs: atlas is unreadable while a card is open (no peeking at neighbours); lots of empty card space on short steps; modal, so no multi-word batching.
