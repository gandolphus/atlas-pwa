# I · Spotlight bar
Idea: clicking any tile floats a Spotlight-style strip (word | input | key hints) in the upper third; the atlas stays untouched, only lightly dimmed, tile ringed.
Optimises: one-line interaction; the placeholder is the instruction (what might it mean? -> it means ... now type it -> done); meaning/sentence/note lines unfold under the strip only when earned.
Speed: guess/meet/recall all advance on Enter; after done, Enter opens the next word in the same strip; width capped (880/1000px) and centred on ultra-wide.
Learned card: same strip, ask-first, Enter reveals (auto-rated good, 1 = again), Down deepens (forms, grammar, also).
Trade-offs: the strip can cover tiles near the top (it scrolls the tile to centre); all context is text lines, so little room for richer visuals; Enter-only recall means an empty Enter just shows the answer and rates hard.
